# The Cape Butler

Static landing page for The Cape Butler.

## Local preview

Open `index.html` in a browser or serve the folder with any static web server.

## GitHub Pages

Publish from the `main` branch, root folder.

## Contact

The site currently uses `hello@thecapebutler.com` in the mailto calls to action. Set up that mailbox or forward it before driving traffic to the site.

## Images

The first version uses free-to-use Unsplash imagery loaded remotely. Replace these with owned Cape photography over time for a more distinctive brand.
